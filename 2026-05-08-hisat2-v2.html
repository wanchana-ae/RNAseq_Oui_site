Project: RNAseq_Oui
Status: Done

🔍 ความแตกต่างจาก v1

  • Input: Trimmed FASTQ จาก fastp (2026-05-08-RNAseq-Oui-Fastp) แทน raw reads
  • Pipeline: HISAT2 → SAMtools sort → StringTie (เหมือนเดิม)
  • เป้าหมาย: เปรียบเทียบ alignment rate ก่อน/หลัง trimming

🛠️ Compute Resources

  • Tool: HISAT2 + SAMtools + StringTie
  • Input: Trimmed FASTQ — /fs4/Mining_data/Method/RNAseq/Oui/Trimmed/
  • Reference: IRGSP-1.0 (IRGSP-1.0_genome)
  • GTF: IRGSP-1.0_representative_transcript_exon_2026-02-05.gtf

💻 Command

hisat2 -p 8 --dta -x $HISAT2_INDEX \
  -1 ${TRIMMED}/${SAMPLE}_1.trimmed.fastq.gz \
  -2 ${TRIMMED}/${SAMPLE}_2.trimmed.fastq.gz \
  -S ${SAMPLE}.sam 2> ${SAMPLE}_hisat2.log
samtools sort -@ 8 -o ${SAMPLE}.bam ${SAMPLE}.sam
stringtie -e -B -p 8 -G $GTF -o ${SAMPLE}.gtf ${SAMPLE}.bam
