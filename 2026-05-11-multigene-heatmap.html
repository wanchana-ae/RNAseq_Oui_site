💡 Notes

  • scale = "row" (Z-score per gene) เหมาะกับ multi-gene heatmap เพราะยีนแต่ละตัวมีระดับ expression ต่างกันมาก — Z-score ทำให้เห็น pattern up/down ชัดขึ้นโดยไม่ถูกยีน highly expressed บดบัง
  • log2FC plot ใช้ scale = "none" เสมอ เพราะต้องการรักษาทิศทาง (+/-) จริง
  • ยีนที่ถูก filter ออก (rowSums(counts) < 10) อาจไม่ปรากฏใน VST matrix — script แจ้งเตือน missing genes ใน console
  • NA handling: เพิ่ม countData <- countData[rowSums(is.na(countData)) == 0, ] ก่อนสร้าง DESeqDataSet เพื่อกันปัญหา NA ใน count matrix
