🧬 RNAseq Oui

โปรเจกต์ RNA-seq วิเคราะห์การแสดงออกของยีนในข้าว (Oryza sativa) เปรียบเทียบระหว่างกลุ่มตัวอย่าง DC, DN, PC, PN และ PNC

📅 Timeline

  • 2026-04-30: เริ่มต้นโปรเจกต์ ตั้ง directory structure และเขียน pipeline script สำหรับรัน samples ทั้งหมด 13 samples อัตโนมัติ 2026-04-30-RNAseq-Oui-Setup
  • 2026-05-01: รัน FastQC ตรวจสอบคุณภาพ raw reads ทั้ง 13 samples 2026-05-01-RNAseq-Oui-QC-Results
  • 2026-05-01: รัน HISAT2 → SAMtools → StringTie ครบทุก sample alignment rate 77–86% 2026-05-01-RNAseq-Oui-HISAT2-Mapping
  • 2026-05-01: รัน prepDE.py สร้าง count matrix — 36,057 genes / 40,249 transcripts × 13 samples 2026-05-01-RNAseq-Oui-prepDE
  • 2026-05-01: รัน DESeq2 v1 — 4 contrasts, overall DEG up 2,909 / down 3,604 genes (padj < 0.1) 2026-05-01-RNAseq-Oui-DESeq2
  • 2026-05-01: รัน DESeq2 v2 — ตัด DC3/DN3 ออก (PCA outlier), 11 samples, overall up 4,717 / down 5,179 (padj < 0.1) 2026-05-01-RNAseq-Oui-DESeq2-v2
  • 2026-05-08: Trim raw reads ด้วย fastp ก่อน re-align (adapter detected in FastQC) 2026-05-08-RNAseq-Oui-Fastp
  • 2026-05-08: Re-run HISAT2 v2 ด้วย trimmed reads — alignment rate 93–96% (v1: 77–86%) 2026-05-08-RNAseq-Oui-HISAT2-v2
  • 2026-05-08: รัน DESeq2 v3 (FINAL) — 11 samples + trimmed reads, 29,909 genes, up 4,833 / down 5,190 (padj < 0.1) 2026-05-08-RNAseq-Oui-DESeq2-v3
