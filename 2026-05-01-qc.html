💻 FastQC Script

#!/bin/bash
#SBATCH --job-name=RNAseq_FastQC
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=8
#SBATCH --mem=32G
#SBATCH --output=./logs/fastqc_%A.log

ml load FastQC

raw_dir="/fs4/Mining_data/Method/RNAseq/Oui/20260428_HN00271762_TRR_Report/rawdata/"
work_dir="/fs4/Mining_data/Method/RNAseq/Oui/"
sample_list="${work_dir}scripts/sample_list.txt"

while IFS= read -r SAMPLE || <a href="#"> -n "${SAMPLE}" </a>; do
    <a href="#">| "${SAMPLE}" =~ ^# </a> && continue

    mkdir -p "${work_dir}FastQC/${SAMPLE}"
    fastqc -o "${work_dir}FastQC/${SAMPLE}" \
           --threads 8 \
           "${raw_dir}${SAMPLE}_1.fastq.gz" \
           "${raw_dir}${SAMPLE}_2.fastq.gz"

    echo "[OK] FastQC done: ${SAMPLE}"
done < "${sample_list}"

💡 Notes

FAIL / WARN ที่ปกติสำหรับ RNA-seq (ไม่ต้องกังวล)

  • Per base sequence content (FAIL R1 / WARN R2): เกิดจาก random hexamer priming bias ที่ปลาย 5' ของ read — เป็นเรื่องปกติใน RNA-seq ทุก library
  • Per sequence GC content (FAIL ทุก sample): GC distribution ของ transcriptome ต่างจาก genomic DNA — ปกติสำหรับ RNA-seq
  • Sequence Duplication Levels (FAIL ทุก sample): เกิดจาก highly expressed transcripts ที่ถูก sequence ซ้ำมาก — คาดได้ใน RNA-seq
  • Per tile sequence quality (WARN/FAIL บางตัว): อุณหภูมิไม่สม่ำเสมอบน flow cell — ไม่รุนแรง ยังผ่านได้

⚠️ จุดที่ต้องระวัง

  • Adapter Content (FAIL R1 ส่วนใหญ่): พบ adapter contamination → ควรทำ adapter trimming ก่อน downstream analysis หากจำเป็น แต่ HISAT2 จัดการได้บางส่วน
  • Per tile sequence quality FAIL: DN1_1, PC1_1, PC1_2, PC2_1 → ควรดู HTML report ประกอบ
